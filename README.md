# FADE (Face's Dynamic Environment)

FADE is a sandbox gamemode for **Combat Team Bravo (CTB)** built to provide an environment for quick operations with minimal setup and **no human Zeus (game master)**. Missions and scenario options are driven by in-game boards and GUIs so players can launch and tailor sessions without external mission editing or a dedicated game master.

The mission focuses on realistic milsim-style mission types: troop insert/extract, CAS and fire support, cargo resupply, HVT, hostage rescue, clear area, and intercept convoy. It is designed for **training** in infantry, rotary piloting, joint fires, and related procedures. **CTB training documentation** (e.g. joint fires, JTAC, CFF, RATEL) is built into the mission via the map briefing and diary for easy in-game access.

Features will evolve as more are developed. Implemented features and upcoming work are tracked in the tables below.

### What’s implemented (per Todo item, excluding AO/JTAC)

- **Surrender mechanic** — Done: 30° cone, 25 m; decision paths (refuse immediately, consider→refuse, consider→surrender); ACE captives integration.
- **Locker room** — Done: optional `LOCKER_1` object; “Locker room” action plays FAC_LockerSlap (add `Sounds\locker_slap.ogg` for custom sound). Extra/Gachi sounds left for Sig.
- **CTB RATEL procedures** — Done: AI sideChat uses “All callsigns, this is  
. … Over/Out.”; RATEL diary note in Notes.

- **Enemy AAA level (global)** — Done: **rsc/EnemyAAA.sqf** governs spawning. None = no AAA. Light/Medium/Heavy = up to 5 AA units: pick 5 random civ zones, within 5 km find highest point, find safe pos, spawn there (Light = static HMG + gunner, Medium = emplaced AA vehicle, Heavy = same vehicle with SAD waypoint). MANPADS = 25% chance per active civ zone when zone activates, max 2 infantry with shoulder-launched AA per zone, non-respawning, SAD waypoint at spawn; despawned when zone despawns or scenario reapplied.
- **Pilot vehicle ammunition / pylons** — Done: “Manage pylons (vehicle loadout)” action when driver of aircraft with pylons; opens vehicle customization.
- **Convoy completion (60% inoperable)** — Done: Intercept Convoy completes when ≥60% of convoy vehicles are inoperable (destroyed or immobile).
- **Enemy AI skill and routing** — Done: Scenario GUI has enemy skill (Low/Medium/High/Very High) and routing (ON/OFF); stored and applied to enemy spawns (skill level and allowFleeing).
- **CTB loadouts in arsenal** — Done: CTB presets (Rifleman, TL, Medic, etc.) in Loadout GUI unit list; same-side only.
- **Save my loadout** — Done: addAction on loadout box saves current loadout; restored on respawn (session-only).
- **One global mission** — Done: single server-wide active mission; any player can start/abort; shared task and cleanup.
- **Respawn fix** — Done: base respawn; loadout restore from saved loadout when available; ACE spectator when applicable.
- **Enemy 50% retreat** — Done: when 50% of mission enemies are dead, each remaining unit rolls retreat by skill (1 − skill); those who retreat move 2 km away from base (opposite direction), full speed. Applied to Troop Extract, CAS, HVT, Hostage, Clear Area, Intercept Convoy, AO.

 AO: core zone, 3 points, BLUFOR/OPFOR, capture; no continuous respawn or user-pick centre yet. JTAC: unit spawns, one 5-line call; full target loop/smoke to come. Locker room: LOCKER_1 + one sound; Gachi/extra sounds for Sig to add.
