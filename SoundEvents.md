SOUND EVENTS -- HELI OPS

SPOKEN (voice from unit, in-person)

Surrender Challenge
- Target surrenders. Used: say3D from target unit. Intent: affirmative, relief, compliance.
- Target refuses. Used: say3D from target unit. Intent: defiance, refusal.
- Target during countdown (optional). Used: say3D from target. Intent: mutter, shout, nervous.
- Civilian surrenders (optional). Used: say3D from civ. Intent: brief plea, e.g. "Don't shoot!"

Troop Transport -- Squad leader to pilot (RATEL / radio procedure; sideChat)
- Squad waiting at pickup. "RZ, Alpha. At pickup. Land within X. Over."
- Popping smoke. "RZ, green smoke. Marking position. Over."
- Embarking. "RZ, embarking. Over."
- Loaded, ready. "RZ, all aboard. Ready for liftoff. Over." / "RZ, proceed to LZ. Land to disembark. Over."
- Disembarking. "RZ, disembarking. Over."
- Disembarked, complete. "RZ, all off. Mission complete. Out."

Cargo / Resupply -- Receiving party at camp (sideChat)
- Offloading cargo. "RZ, receiving. Offloading cargo. Wilco. Out."


OVER THE RADIO (command/briefing style, radio effect)

Mission assignment
- Mission assigned. Used: playSound to player. Intent: radio brief, e.g. "Troop Insert. LZ grid X."
- Mission succeeded. Used: playSound. Intent: success confirmation, chime.
- Mission failed. Used: playSound. Intent: failure tone, e.g. casualties, timeout.
- Mission aborted. Used: playSound. Intent: cancelled, player-initiated.

Vehicle spawn/despawn
- Aircraft spawned. Used: playSound. Intent: confirmation, e.g. "X spawned at pad Y."
- Land vehicle spawned. Used: playSound. Intent: same.
- Vehicle despawned. Used: playSound. Intent: confirmation.
- Spawn/despawn failed. Used: playSound. Intent: error beep, negative feedback.

Scenario / loadout
- Scenario applied. Used: playSound. Intent: time, weather, factions updated.
- Loadout applied. Used: playSound. Intent: kit confirmation.

Surrender Challenge -- system feedback (not target speaking)
- Processing, validation errors, initiated, surrendered, refused. Used: playSound. Intent: radio-style status to player.
